# What Forever has: notes for the Forever addons

These are facts about WoW Forever's client (interface 16001) that the Forever addons (Core, Tweaks, Compendium) rely on. Each was checked against one of two sources, both on their `forever` branch:

- **[BIR]** Ketho/BlizzardInterfaceResources: the API dump. `Resources/GlobalAPI.lua` lists global and `C_` functions, `Events.lua` lists events, `CVars.lua` lists console variables with defaults, `Templates.lua` lists XML templates and font objects, and `AtlasInfo.lua` lists atlases.
- **[UI]** Gethe/wow-ui-source: Blizzard's own interface code, under `Interface/AddOns/`.

The developer documentation at community.developer.battle.net covers Blizzard's web APIs only, not the in-game Lua API. Addons can't make web requests, so the web API is only noted at the end of this page, for tools outside the game.

When something new is used, check it here first, then add it to this page. Don't write fallbacks for things Forever has.

## The client

- Forever runs the Midnight (Mainline) client. Some Blizzard addons have a `Camelot` version that Forever loads instead of the `Mainline` one. The minimap is one of them: `Blizzard_Minimap/Camelot/Minimap.lua`. [UI]
- Addon code is restricted the way Midnight restricts it. Some values are *secret*: you can pass them on, but you can't compare them or do arithmetic with them. `issecretvalue(v)` tells you whether a value is secret. `frame:GetFrameStrata()` can return one. [BIR]

## Functions present

- **Error handling:** `securecallfunction`, `seterrorhandler`, `geterrorhandler`, `debugstack`, `debugprofilestop`. [BIR GlobalAPI]
- **Events:** `C_EventUtils.IsEventValid(event)`. Registering an event the client doesn't have is an error, so check first. [BIR GlobalAPI]
- **Timers:** `C_Timer.After`, `C_Timer.NewTimer`, `C_Timer.NewTicker`. [BIR GlobalAPI]
- **Addons:** `C_AddOns.GetAddOnMetadata`, `C_AddOns.IsAddOnLoaded`. [BIR GlobalAPI]
- **The game's addon profiler:** `C_AddOnProfiler.IsEnabled`, `GetAddOnMetric`, `GetOverallMetric`, `GetApplicationMetric`, `GetTopKAddOnsForMetric`. The metrics come from `Enum.AddOnProfilerMetric`; this addon uses `RecentAverageTime` and `PeakTime`. [BIR GlobalAPI, LuaEnum]
- **Settings:** `Settings.RegisterCanvasLayoutCategory`, `RegisterCanvasLayoutSubcategory`, `RegisterAddOnCategory`, and `C_SettingsUtil.OpenSettingsPanel(categoryID)` to open them. [BIR]
- **Chat:** `ChatFrameUtil.GetTimestampFormat()` with `TimeUtil.BetterDate(format, time())`, to stamp lines the way the chat timestamp option does. [UI `Blizzard_ChatFrameBase/Shared/ChatFrameUtil.lua`]
- **UI helpers:** `CreateMinimalSliderFormatter`, `NineSliceUtil.ApplyLayout`, `MenuUtil.CreateContextMenu`, `GameTooltip_Hide`, `StaticPopup_Show`, `Screenshot`. [BIR FrameXML, GlobalAPI]

- **Spells and range:** `C_SpellBook.GetNumSpellBookSkillLines`, `GetSpellBookSkillLineInfo` (itemIndexOffset, numSpellBookItems, offSpecID), `GetSpellBookItemInfo(slot, Enum.SpellBookSpellBank.Player)` (itemType, spellID, isPassive), `IsSpellBookItemHarmful`, `IsSpellBookItemHelpful`; `C_Spell.GetSpellInfo` (minRange, maxRange), `C_Spell.SpellHasRange`, `C_Spell.IsSpellInRange(spell, unit)` (true, false, or nil when it can't check; not a secret return). [BIR GlobalAPI, UI `Blizzard_APIDocumentationGenerated/SpellBookDocumentation.lua`, `SpellDocumentation.lua`]
- **Casting:** `UnitCastingInfo` (name, text, texture, startTimeMS, endTimeMS, isTradeSkill, castID, notInterruptible, spellID) and `UnitChannelInfo` (the 8th value is the spellID). [BIR GlobalAPI]
- **Units and gear:** `UnitAffectingCombat`, `UnitCanAttack`, `UnitExists`, `UnitIsDeadOrGhost`, `GetInventoryItemDurability(slot)`, `C_ClassColor.GetClassColor(classFile)`, `GetCursorPosition`; `GetCursorInfo()` ("item", itemID, link while an item is held) and `ClearCursor`, with an EditBox's `OnReceiveDrag` script, for dropping an item from the bags onto a box (the item lists' Item box). [BIR GlobalAPI, WidgetAPI]
- **Dropdowns:** `WowStyle1DropdownTemplate` mixes in `DropdownSelectionTextMixin`: `SetSelectionText(fn)` sets the button's text; `root:CreateCheckbox` items answer `MenuResponse.Refresh`, so the menu stays open while ticking, and take `SetTitleAndTextTooltip(title, text)`. [UI `Blizzard_Menu/MenuTemplates.lua`, `MenuUtil.lua`]

## Not present: don't use

- `MouseIsOver(frame)`. Use `frame:IsMouseOver()` instead.
- `Minimap_UpdateRotationSetting`. Forever's minimap follows the `rotateMinimap` CVar by itself. [UI Camelot Minimap]
- `C_Console`. Nothing replaces it.

## Events used

- `ADDON_LOADED`, `PLAYER_LOGIN`, `PLAYER_ENTERING_WORLD`, `PLAYER_REGEN_ENABLED`.
- `CVAR_UPDATE`. It is a `SynchronousEvent`, so it fires inside your own `SetCVar` call. [UI `Blizzard_APIDocumentationGenerated/ConsoleDocumentation.lua`]
- `ADDON_ACTION_BLOCKED`, `ADDON_ACTION_FORBIDDEN`, `LUA_WARNING`.
- `PLAYER_TARGET_CHANGED`, `UPDATE_MOUSEOVER_UNIT`, `NAME_PLATE_UNIT_ADDED`, `ZONE_CHANGED_NEW_AREA`, `GROUP_ROSTER_UPDATE`.

All are in [BIR Events].
- `UNIT_SPELLCAST_START`, `_DELAYED`, `_STOP`, `_FAILED`, `_INTERRUPTED`, `SPELLS_CHANGED`, `UNIT_FLAGS`, `UPDATE_INVENTORY_DURABILITY`, `SCREENSHOT_SUCCEEDED`. [BIR Events]

## Console variables

Forever's defaults, from [BIR CVars]:

| CVar | Default | Notes |
|---|---|---|
| `farclip` | 1000 | View distance. Much higher values (like 7000) are the likeliest cause of stutter. |
| `rotateMinimap` | 0 | The game resets it at login (Forever Tweaks' Rotate Minimap set it again until 1.6.0; Forever++'s Console Variables can lock it). |
| `nameplateShowFriendlyNpcs` | 0 | Layer Info reads layers faster with this on. |
| `mapFade` | 1 | Whether the world map fades out while you move. |
| `SpellQueueWindow` | 400 | No setting in Forever's Options. |
| `cameraDistanceMaxZoomFactor` | 1.0 | Forever's Options slider stops at 2.0 (`Camelot/ControlsOverrides.lua`); Forever++'s Console Variables page sets it past that. |
| `nameplateMaxDistance` | 45 | No setting. |
| `ffxGlow`, `ffxDeath` | 1 | No setting. |
| `screenshotFormat` | jpeg | No setting (`png`, `tga` also taken). |
| `showLootSpam` | 1 | No setting. |

The view distance and detail CVars (`groundEffectDensity`, `lodObjectCullSize`, `lodObjectFadeScale`, `ResampleAlwaysSharpen`) had a module until 1.4.0; the game's Graphics options and console variable editors set them now.

### Already in the game's Options

These CVars have a setting in Forever's own Options [UI]:

- `statusTextDisplay` and `statusText`: Interface > Display > Status Text (`Blizzard_SettingsDefinitions_Frame/Interface.lua`).
- `Sound_EnableErrorSpeech`: Audio > Error Speech (`Blizzard_SettingsDefinitions_Shared/Audio.lua`).
- `nameplateShowFriendlyNpcs`: Nameplates (`Blizzard_SettingsDefinitions_Frame/Nameplates.lua`).
- `farclip`, ground clutter and environment detail: only as presets (View Distance, Ground Clutter, Environment Detail), not as exact values. `ResampleSharpness` has a slider; `ResampleAlwaysSharpen` and `lodObjectFadeScale` have none (`Blizzard_SettingsDefinitions_Shared/Graphics.lua`).

These have **no** setting: `rotateMinimap`, `mapFade`, `scriptErrors` (only `/console scriptErrors 1`), and the others in the table above. Others with none that could make tweaks: `nameplateOccludedAlphaMult` (0.4), `autoLootRate` (150), `alwaysCompareItems`, `UberTooltips`, `screenshotQuality` (3), `ffxNether`, `cameraIndirectVisibility` and `cameraIndirectOffset` (6), `autoDismount`, `autoUnshift`, `autoStand`, `ActionButtonUseKeyDown`.

The game also has these, with no addon:
- An FPS counter: the `TOGGLEFPS` key binding (Ctrl+R) calls `FramerateFrame:Toggle()` (`Blizzard_FrameXML/Bindings_Camelot.xml`).
- A tooltip on the Game Menu micro button with latency, FPS, bandwidth and per-addon CPU: `MainMenuBarPerformanceBarFrame_OnEnter` in `Blizzard_PerformanceBar/PerformanceBar.lua`.

- **Forbidden tables:** Blizzard's protected frames are *forbidden* to addon code: reading any key from one (a field, or a method such as `IsForbidden`) raises "attempted to index a table that cannot be accessed while tainted". ## The web API (outside the game)

Blizzard's web API (`{region}.api.blizzard.com`) has Forever data too. It's undocumented. The notes below come from community probing on November 5-6, 2026, collected in the forum thread [WoW Forever API: what works so far](https://us.forums.blizzard.com/en/blizzard/t/wow-forever-api-what-works-so-far-plus-a-ts-client/60334), and may change.

An addon can't call it. It's for websites, bots and companion tools.

- **Namespaces:** `static-forever-{region}` for game data, `dynamic-forever-{region}` for rulesets and auctions, and `profile-forever-{region}` for characters and guilds. The regions are US, EU, KR and TW. Static data was at version `1.60.1_70399`.
- **Rulesets replace realms:**
  - The realm index returns 404.
  - `/data/wow/ruleset/index` lists the rulesets. In the US and EU they are 1 (PvP), 2 (Normal), 3 (Roleplay) and 15 (Roleplay PvP); in KR and TW only 1 and 2.
- **Characters have no realm:**
  - They're named `{name}-{surname}`, unique per region: `/profile/wow/character/{name}-{surname}?namespace=profile-forever-{region}`.
  - A profile has `surname` and `ruleset` where other versions have `realm`.
  - A character only shows up from level 10, after logging out.
  - Most sub-pages work. `hunter-pets` doesn't.
- **Guilds:** `/data/wow/guild/{slug}` with `/roster`, `/activity` and `/achievements`.
- **Auctions:**
  - `/data/wow/ruleset/{id}/auctions/` lists the houses. It needs the trailing slash.
  - `/data/wow/ruleset/{id}/auctions/{houseId}` and `.../commodities` return the listings.
  - Every ruleset returns the same 15 houses.
- **Items:** many older items return 404 from `/data/wow/item/{id}`.

In game, the matching pieces are surnames, with `C_PlayerInfo.ShouldDisplaySurname` and `C_NameUtil.ReplaceSurnameSeparatorWithLinkSeparator` [BIR GlobalAPI]. Forever Tweaks uses neither realms nor names, so none of this changes it.
